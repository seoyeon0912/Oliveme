# 🌿 OliveMe

자연 유래 화장품을 주제로 제작한 웹 쇼핑몰 프로젝트입니다.

## 📌 주요 기능

* 회원가입 및 로그인
* 이메일 인증
* 아이디 찾기 / 비밀번호 찾기
* 로그인 2차 인증
* 장바구니 관리
* 상품 주문 및 구매내역 조회
* 마이페이지
* 개인정보 수정
* 이메일 변경 시 재인증
* 상품 추천 기능

## 🛠 기술 스택

* Node.js
* Express.js
* EJS
* HTML5
* CSS3
* JavaScript
* JSON

## 🔒 보안 기능

* bcrypt 비밀번호 암호화
* 이메일 인증
* 로그인 2차 인증
* 로그인 실패 횟수 제한
* 개인정보 수정 시 이메일 재인증

## 🚀 실행 방법

1. 패키지 설치

```bash
npm install
```

2. 서버 실행

```bash
node app.js
```

3. 브라우저 접속

```text
http://localhost:3000
```
